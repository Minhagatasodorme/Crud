# REST API + CRUD

CRUD feito em Golang integrado a uma REST API  
Retorna em formato Json em todos os métodos

# Parâmetros
`Id: Int autoincrement`  
`Nome: String`  
`Email: String`

# Bibliotecas

- [SqLite](https://github.com/mattn/go-sqlite3)
- Go 1.26.5

# Métodos

- `GET /get/usuarios`  
- `GET /get/usuarios/all`
- `POST /post/usuarios`
- `DELETE /delete/usuarios`
